# Unreleased
* AK brakes reduce recoil about 30% less, so a fully built AK no longer goes below zero recoil
* AKs recoil more per shot, so an AK with a brake leads an AR with a flash hider by as much as a suppressed AR leads a suppressed AK
* AK base recoil: AK-74M 50 -> 55, AK-12 42 -> 52, AK-105 46 -> 55, AK-101 47 -> 54, AK-102 51 -> 54, AKS-74 52 -> 54, AK-103 48 -> 61, AK-104 50 -> 61
* suppressors no longer reduce recoil. Those that mount on a flash hider or brake (Griffin M4SD II, AAC 762-SDN-6, SOCOM556-MONSTER, DT338, Trash PANDA, SOCOM338-TI) cancel its recoil bonus instead of adding to it
* 5.56 rifles that fit no brake recoil less: M4A1 62 -> 50, MCX Virtus 58 -> 47, CQ 68 -> 56, QBZ-97 54 -> 34
* QBZ-97 cheek rest no longer reduces recoil
* LMGs recoil less than the rifle they're built on and handle worse: KAC LAMG recoil 38 -> 48, RPK-74 recoil 56 -> 53 and ergonomics 41 -> 36
* AS VAL and VSS recoil about like a suppressed 7.62x39 AK instead of next to nothing: AS VAL recoil 40 -> 65.5, VSS recoil 36 -> 67 and ergonomics 52 -> 66
* RIA VR80 ergonomics 55 -> 39, so a fully built one no longer handles better than most rifles
* M14 Troy SASS chassis no longer stacks its -14 recoil / +8 ergonomics with the stock and grip mounted on it
* FAL stocks on the AR stock scale: the aftermarket Series X (-20 / +16 -> -16 / +8) beats an AR stock on the FAL buffer tube, the factory Folding Para (-18 / +14 -> -9 / +16) trails one
* bullpups handle better: AUG A3 ergonomics 65 -> 85, QBZ-97 ergonomics 41 -> 80
* SCAR-L ergonomics 56 -> 70, so its built-in stock counts as a mid-range AR stock
* STV-380 recoil 44 -> 40 and ergonomics 53 -> 70, so its built-in stock and flash hider count as a mid-range AK stock and a flash hider
* battle rifles and DMRs handle worse and recoil more, so a fully built one with a brake recoils a bit more than a 7.62x39 AK with one:
  * recoil: FAL 70 -> 76.5, M14 60 -> 73, SCAR-H 44 -> 58, SR-25 38 -> 78, Galil ACE 48 -> 69, M305 66 -> 74, RFB 54 -> 58, SVDS 36 -> 58
  * ergonomics: FAL 45 -> 38, M14 44 -> 40, SR-25 60 -> 36, Galil ACE 60 -> 40, M305 46 -> 40, SVDS 45 -> 30, RFB 58 -> 83
* MK-47 is an all-around better SKS: MK-47 recoil 46 -> 50 and ergonomics 50 -> 56, SKS ergonomics 43 -> 35
* SMGs recoil more than rifles and handle better:
  * recoil: AKS-74U 56 -> 65.5, PP-19 Vityaz 62 -> 57, P90 42 -> 40, MPX 52 -> 61, Vector 48 -> 47.5, MP5 55 -> 49, MP5K 58 -> 51, MP5SD 40 -> 38, Honey Badger 52 -> 66.5, Rattler 56 -> 55
  * ergonomics: AKS-74U 58 -> 67, PP-19 Vityaz 58 -> 65, P90 70 -> 93, MP5 68 -> 85, MP5K 70 -> 84, MP5SD 62.5 -> 83, Honey Badger 55 -> 63, Rattler 45 -> 61
  * SMG-only brakes reduce recoil less: PP-19 muzzle -22.5 -> -10, P90 flash hider -22 -> -8
